# LearningScience.ai Landing Page - Enhanced Requirements & Specifications

## Product Requirement: "Productive Struggle" Book Sales Platform

**Purpose:** To transform overwhelmed educators into confident AI-powered teaching innovators by selling Dr. Ernesto Lee's groundbreaking book "Productive Struggle: A Research-Based Approach to Teaching and Learning with Artificial Intelligence" and accompanying workshops.

**Core Value Proposition:** Unlike AI tools that eliminate friction (and learning), this book teaches educators how to engineer "productive friction" that amplifies student thinking while leveraging AI's power.

## Updated Pricing Structure

**Physical Book:** $39.99 + $5.00 Shipping  
**Ebook:** $34.99  
**Workshop:** $499 per person (Contact for group rates)

## Technical Specifications

**Framework:** React with Next.js 14+  
**Styling:** Tailwind CSS + DaisyUI  
**Animation:** Framer Motion + MagicUI components  
**Components:** Shadcn/ui base + MagicUI + ReactBits + 21st.dev  
**Icons:** Heroicons + custom educational SVGs  
**Fonts:** Inter (primary), DM Serif Display (headings)
